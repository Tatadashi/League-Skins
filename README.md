# League-Skins

I made this so that my friends and I could view League skins
without having to login to the client. With League being my forever and favorite game, being able to incorporate my two main interests was really nice and fun. It turned out a lot better
than I thought and I learned a lot making it. I still would like
to add more features to it in the future and obviously keep it up
to date per latest patch.
